PROJECT_NAME: tech-gadget-store
REQUIREMENTS:
- Create a multi-page Tech Gadget Store website using only HTML, CSS, and vanilla JavaScript.
- The website should have a homepage with a hero banner, featured products, and a responsive layout that adjusts from three columns to one.
- The website should have a shop page with category filtering, sorting options, and live search.
- The website should have a product detail page with images, specifications, badges, and an Add to Cart button.
- The website should have a cart page showing items stored in localStorage with quantity controls and totals.
SHARED_COMPONENTS:
- Responsive header
- Footer
- Cart section
SHARED_ASSETS:
- styles.css
- script.js
- data.json
FILES:
index.html, shop.html, product-detail.html, cart.html, styles.css, script.js, data.json
ORDER:
index.html -> shop.html -> product-detail.html -> cart.html -> styles.css -> script.js -> data.json
FILE_REQUIREMENTS:
* index.html: hero banner, featured products, responsive layout
* shop.html: category filtering, sorting options, live search
* product-detail.html: images, specifications, badges, Add to Cart button
* cart.html: items stored in localStorage, quantity controls, totals
* styles.css: global stylesheet
* script.js: global script
* data.json: shared data source
STEPS:
Step 1: index.html Constraints: The website should have a homepage with a hero banner, featured products, and a responsive layout that adjusts from three columns to one, using the responsive header and footer shared components, and referencing the styles.css and script.js shared assets.
Step 2: shop.html Constraints: The website should have a shop page with category filtering, sorting options, and live search, using the responsive header and footer shared components, and referencing the styles.css and script.js shared assets.
Step 3: product-detail.html Constraints: The website should have a product detail page with images, specifications, badges, and an Add to Cart button, using the responsive header and footer shared components, and referencing the styles.css and script.js shared assets.
Step 4: cart.html Constraints: The website should have a cart page showing items stored in localStorage with quantity controls and totals, using the responsive header and footer shared components, and referencing the styles.css and script.js shared assets.
Step 5: styles.css Constraints: The website should have a global stylesheet that is used by all pages, referencing the shared components and assets.
Step 6: script.js Constraints: The website should have a global script that is used by all pages, referencing the shared components and assets.
Step 7: data.json Constraints: The website should have a shared data source that is used by all pages, referencing the shared components and assets.
