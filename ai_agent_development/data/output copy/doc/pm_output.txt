PRODUCT:

USER_REQUIREMENT:
Create a multi-page Tech Gadget Store website using only HTML, CSS, and vanilla JavaScript. Include a homepage with a hero banner, featured products, and a responsive layout that adjusts from three columns to one. Add a shop page with category filtering, sorting options, and live search. Add a product detail page with images, specifications, badges, and an Add to Cart button. Add a cart page showing items stored in localStorage with quantity controls and totals. All pages must share the same responsive header with logo, menu, search bar, and a cart section showing item count and subtotal, as well as a footer. Products must be hardcoded directly in HTML, and all functionality must work without using any icons or special symbols.

REQUIREMENTS:
This project aims to create a functional e-commerce website for tech gadgets. The website should be user-friendly, responsive, and accessible. The target users are tech enthusiasts and consumers looking for gadgets online. Success criteria include a fully functional website, proper layout, and correct functionality of features.

- Add to Cart button and cart page
