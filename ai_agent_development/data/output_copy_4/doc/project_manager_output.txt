PROJECT_NAME: clothing-store-homepage

REQUIREMENTS:
The homepage should have a modern, minimal aesthetic. The header should include a left-aligned store logo, navigation links for Men, Women, Kids, and Accessories, a centered search bar that filters products as the user types, and a cart summary on the right showing item count and subtotal. The layout must be clean, spacious, and fully responsive, with neutral color tones and subtle shadows that match a minimalist fashion brand feel.

SHARED_COMPONENTS:
  - Header with search bar (#search-input) and cart section (#cart-count, #cart-subtotal)
  - Footer with company info, navigation links, and contact information

SHARED_ASSETS:
  - products.json (file) at products.json ⚠ CRITICAL: Products must be loaded from this JSON file, not hardcoded!
  - styles.css (file) at styles.css
  - script.js (file) at script.js

FILES:
index.html, shop.html, cart.html, styles.css, script.js, products.json

ORDER:
products.json -> index.html -> shop.html -> cart.html -> styles.css -> script.js

FILE_REQUIREMENTS:
- index.html: The homepage should have a modern, minimal aesthetic. The header should include a left-aligned store logo, navigation links for Men, Women, Kids, and Accessories, a centered search bar that filters products as the user types, and a cart summary on the right showing item count and subtotal.
- shop.html: The shop page should display a list of products with images, prices, and categories. The page should also include a filter dropdown for categories and a sort dropdown for price and popularity.

- styles.css: The stylesheet should include styles for the header, footer, and product list. The styles should be modern, minimal, and responsive.
- script.js: The script should include functionality for the search bar, filter dropdown, and sort dropdown. The script should also include functionality for adding and removing products from the cart.
- products.json: The products.json file should include a list of products with images, prices, and categories.
