PROJECT_NAME: tech-gadgets-website

REQUIREMENTS:

The website should be built using only HTML, CSS, and vanilla JavaScript. The website should have a responsive layout that adjusts from three columns to one. The website should have a homepage with a hero banner, featured products, and a responsive layout. The website should have a shop page with category filtering, sorting options, and live search. The website should have a product detail page with images, specifications, badges, and an Add to Cart button. The website should have a cart page showing items stored in localStorage with quantity controls and totals.
