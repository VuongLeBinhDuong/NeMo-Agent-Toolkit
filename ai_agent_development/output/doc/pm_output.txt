REQUIREMENTS:
- Build a responsive fashion marketplace website with a clean, modern design.
- The website should feature a compact sticky header with logo, navigation, search, and a cart badge that updates in real time.
- JavaScript should handle live search, filtering, sorting, and cart updates.
- The website should have a full-width hero section displaying sliding banners with text overlays and manual or auto-play controls.
- Products should be shown in a responsive grid with hover effects, badges, and dynamic rendering based on search and filters.
- The shop view should add pagination and advanced filters such as category and price range, using a shared global product state.
- Product details should be displayed in a responsive layout with image switching, option selection, and add-to-cart actions.
- The cart should appear as a page or slide-out panel with animated transitions, quantity controls, subtotal calculation, and persistent storage via localStorage.
- CSS should ensure consistent typography, spacing, and responsiveness, while JavaScript should manage all interactivity and state synchronization.

- Persistent storage via localStorage
